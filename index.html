章节 / 01

人是一个
维持自身稳定的
开放系统

最底层命题

生命体不是孤立的石头。要活着，它必须不停地感知环境、选择行为、维持内部稳定。

学习，是"选择行为"中代价最昂贵的一种——它要求大脑维持一种很贵的状态。

章节 / 02

两种模式
清醒 vs 睡眠

既要处理外界，又要维护自身

生命体不能同时把全部资源用于对外输出和对内维护。所以它必须有两种模式，并周期性切换。

章节 / 03

清醒的
四种负担

"累" 是怎么积累起来的

清醒不是免费的。它持续给大脑加压，四种负担同时积累，最终逼迫系统切换。

章节 / 04

睡眠不是关机
它有内部结构

N1 · N2 · N3 · REM

一个完整的睡眠周期约 90 分钟，由四个阶段组成，循环 4-6 次。每一个阶段做不同的事——它们不能互相替代。

章节 / 05

节律系统
决定"何时该睡"

两条曲线 + 一组激素

身体不靠"感觉累"决定该睡。它靠两条彼此独立的曲线——睡眠压力 H 与 昼夜节律 C——共同标记睡眠窗口。

章节 / 06

睡意窗口
为什么会被打断

困意 ≠ 一定能睡着

困不是"开关"，是一段窗口期。窗口需要五个条件同时对齐——任何一个被破坏，窗口就会关上。

章节 / 07

睡少 → 学习崩
这条因果链

为什么"撑一下"撑不过几天

睡眠不足不是"明天补回来"那么简单。它会从第一节课开始一路侵蚀，直到把编码、巩固、提取三个环节全部拆掉。
