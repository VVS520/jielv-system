00 · OVERVIEW

这不只是"睡眠"

恢复—节律系统的精确定义

"睡觉有助学习"——这种说法太粗糙了。

恢复—节律系统 = 开放生命系统在清醒对外输出后，为了重新维持内部稳定，通过睡眠压力、昼夜节律、唤醒调节和睡眠结构，把身体与大脑周期性切换到内部维护状态的控制系统。

它要回答的核心问题是：

"为什么我们必须睡觉？"

答案不在心理学，而在控制论——任何对外开放的系统，都需要周期性回到"内部维护"状态。

01 · AXIOMS

五条公理

为什么这个系统必须存在

公理 1
生命体是开放系统，必须维持内部可运行状态。

持续与外界交换物质、能量、信息、反馈。变量须维持在可运行范围：血糖、血氧、体温、神经兴奋度、激素、免疫……这就是稳态。
↓
公理 2
为生存与学习，必须对外感知、预测、行动。

清醒 = 输入开放 + 信息加工 + 行为控制 + 记忆更新。但这种状态会持续消耗、积累损耗。
↓
公理 3
清醒一定会积累损耗，无法无限持续。

代谢产物堆积、突触强度饱和、神经元疲劳、情绪与控制资源耗竭。必须有"还债机制"。
↓
公理 4
地球有 24 小时光暗周期。

生命体把节律内化为内部时钟——昼夜节律 C。它决定"何时该清醒、何时该休息"。
↓
公理 5
必须有切换机制：清醒 ⇌ 睡眠。

不能同时既对外输出又对内维护。系统必须能在两种模式间稳定、安全地切换。
02 · VARIABLES

四个内生变量

系统运作的核心状态量

Homeostatic Pressure
H · 睡眠压力
清醒时间越长，H 越高。代谢产物（如腺苷）在大脑积累，产生"困意"。睡眠时 H 下降，清醒时持续上升。

直觉：它是一个"清醒负债计数器"。
Circadian Rhythm
C · 昼夜节律
由视交叉上核（SCN）驱动的约 24 小时内部时钟。受光照重置。决定"什么时间该清醒/该睡"，不依赖你累不累。

直觉：它是身体的"时区"。
Arousal
A · 唤醒水平
由压力、咖啡因、情绪、危险感等驱动的"强行清醒"力量。可以暂时压制 H 和 C。

直觉：它是身体的"应急油门"，但会透支。
Sleep Structure
S · 睡眠结构
睡眠不是单一状态，而是 NREM（浅→深）与 REM 周期性交替。结构完整，恢复才完整。

直觉："睡了 8 小时"不等于"睡好了"。
03 · ALGORITHM

系统核心算法

困意是怎么计算出来的

P = f ( H , C , A )
SLEEP PROPENSITY FUNCTION

"想睡"不是单一信号，而是三个变量的合成结果：

  • H 高 + C 低 + A 低 → 强烈想睡（深夜疲劳）
  • H 高 + C 高 + A 高 → 困但睡不着（熬夜兴奋）
  • H 低 + C 低 → 该睡睡不着（白天补觉失败）
  • H 高 + C 高 → 清醒高效（午后专注力）

06 · STRUCTURE

睡眠周期

前半夜与后半夜，做的是不同的事

一夜睡眠包含 4-6 个 90 分钟循环。但每个循环的"组成比例"完全不同。

FIRST HALF
前半夜
NREM 深睡眠占比高
身体修复 · 知识沉淀
SECOND HALF
后半夜
REM 占比逐渐升高
情绪整理 · 创造联想

这意味着什么

  • 早睡晚起 ≠ 睡得久就够。掐头去尾都会让结构残缺。
  • 凌晨 2 点睡 + 早 7 点起 → 失去 REM 黄金期。第二天易怒、思维僵化。
  • 晚上 11 点睡 + 凌晨 4 点起 → 失去深 NREM。身体没修好、知识没固化。
睡眠时长重要，但睡眠结构更重要。完整的 7-8 小时 ≠ 任意时段拼凑的 7-8 小时。
